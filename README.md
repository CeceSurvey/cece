# 测策 · 工程测量学习与实训系统

面向土木工程测量课程学习与实训的辅助工具：**全站仪测绘**（点位录入 + 平面成图）、**水准测量**（高差高程 + 成果整理）、**角度测量**（测回法角值计算）。

零依赖、纯静态、完全离线，数据只存在本机。

---

## 一、如何打开

**方式一：直接打开（最快）**

双击 `index.html`，用浏览器打开即可使用。数据保存在该浏览器的本地存储中。

**方式二：本地服务（推荐，可"添加到主屏幕"）**

在本目录执行：

```bash
python -m http.server 8765
```

然后用平板/电脑浏览器访问 `http://127.0.0.1:8765`。在浏览器菜单中选择「添加到主屏幕」，即可像 App 一样全屏启动，横竖屏自动切换。

**方式三：安装安卓 APK**

`dist/测策-v3.0.3.apk`（Android 7.0 及以上）。覆盖安装不会丢失原有工作数据（同签名证书）。

改完网页代码后重新打包：

```bash
JAVA_HOME=<JDK17> bash android/build.sh
```

详见 `docs/安卓打包指南.md`。

## 二、页面与功能

### 1. 首页

「新建工作」「工作管理」「数据分析」「关于程序」四张卡片。窄屏自动改为纵向堆叠。

### 2. 新建工作

- 先选**工作类型**：全站仪测绘 / 水准测量 / 角度测量
- 填工作名称（默认按日期时间生成）
- 水准测量额外填「起点 / 终点已知高程」，也可以进去再填
- 点「创建并开始」直接进入工作区

### 3. 工作管理

- **搜索**：按工作名称实时过滤
- **筛选**：按类型（全站仪 / 水准 / 角度）
- **排序**：最近修改 / 最早创建 / 名称 A→Z / 按类型
- **批量**：多选后可批量导出为一个备份文件、批量删除
- 每张卡片：编辑 / 只读 / 重命名 / 删除；页面右上角两个图标按钮分别是「从文件导入工作」（支持单个工作或整包备份）与「批量管理」

### 4. 全站仪测绘

表头：`排序 | 点号 | 棱镜高 | N(X) | E(Y) | H(Z) | 备注`（单位 m）

数字格（棱镜高 / N / E / H）统一**三位小数**：填 100 或 56.1，离焦后自动补成 100.000 / 56.100；空行不补。

**点号智能编号**

新建工作时点号全部留空。当你在某个空点号格上聚焦，程序会向上找最近一个数字点号，用**浅灰色**给出「+1」的预测值；直接点别的格子（不输入）就把它落成真实点号，输入了则以你输入的为准。

**点位分类**

- 默认四类：碎部点、控制点、测站点、辅助点；**新增的点默认是碎部点**
- 备注里出现某个类型的关键词，程序自动把该点归入该类型，点号字体颜色随之变化
- 若备注同时命中两类关键词，程序**不会**强行分类，直到只剩一类能匹配
- 点表格上方的「编辑点」进入编辑模式，点中某个点会高亮，**再点一次**可指定类型（手动指定后不再被备注覆盖，也可切回"按备注自动识别"）
- 点类型弹窗只改**这一个点**，弹窗内不提供默认点设置；要改默认点到「关于程序 → 程序设置」，点某类的「修改」，勾上**「选择该点为默认点」**——默认点只能有一个，设了新的旧的自动取消，列表里该类型会带「默认」标记
- 类型与关键词在「程序设置」里自定义

**连线**

- 点表格上方的「连线」进入连线模式，在图上**依次点选多个点**（≥2），程序按点选顺序把相邻两点连成折线；选中的点显示橙色圈，并用虚线预览待连折线，点底部 **✓** 一次性确认（✕ 取消）；再点一次已选中的点可取消该点
- 连线模式下点中一条线，该线会加粗并出现光带高亮；**再点一次**弹出「连线 · 颜色与删除」：黑 / 红 / 橘 / 黄 / 绿 / 蓝 / 紫 / 主题色，或在同一弹窗里直接删除该线
- 连线按"点"关联，拖动排序、改点号都不会错位
- 「编辑点」与「连线」互斥，开启时双击空白处不再触发"自适应"

**平面图**

- X 轴（N 坐标）纵轴向上，Y 轴（E 坐标）横轴向右，等比例不变形
- 点号自动避让，点位密集时也不会互相压字
- 数据变化自动缩放到最佳视野；手动缩放后保持你的视角

### 5. 水准测量

- 记录表按手簿排布：**测站 / 点号 / 视距 / 后视读数 a / 前视读数 b / 高差 h / 高程 H / 备注 / 管理**，每测站占两行（后视点、前视点），测站、高差合并成一格
- **两个点号各有一个视距格**，不合并：同一测站前后视视距不同也能照实填；Σ 视距取两者之和，成果表的「测段距离」取两者的平均值（即该段实际长度）
- 五列读数格**都能填**：后视点行的「后视读数」、前视点行的「前视读数」参与本站高差；「后视点的前视读数」「前视点的后视读数」只留档、不参与计算。填错位置或只填一侧时表下会指出是第几站，不阻断录入
- 点号自己填（默认留空，不自动生成），中间点前后视共用同一格；备注自己填（如「已知」）
- **闭合 / 附合不用切**，由数据自动判定：标题栏的「H终」留空（或填得与起点高程相同）按**闭合**算；填了不同的终点已知高程就按**附合**算，旁边的标记会跟着变，表下提示也会写成「闭合水准 / 附合水准」。记录表里只有起点「高程」格是输入格，其余点高程由程序推算
- **高差 h = a − b**、**高程 H = 起点高程 + 累计高差**，自动计算；没有数据的格子保持空白，不写占位符
- 新建时填**起点高程**与**容许闭合差系数**（如 40 → f_h允 = 40√L，L 为测段距离合计 km）；终点高程在标题栏「H终」里填，顶部「容差 40√L」按钮可随时改系数
- 数字格一律**三位小数**：填 56.1 离焦后自动补成 56.100（视距、五个读数格、起点高程、H终；空着不补）
- 默认新建 **2 站**；每站右侧「编辑」可上下移动该站（对测站排序）或删除该站（二次确认）
- 检核行：Σ 视距、Σa、Σb、Σh，以及 **Σa−Σb =**、**Σh =**、**H终−H始 =**（都带等号，后面跟数值）
- **成果表**同样两行一测段：测段编号 / 点号 / 测段距离 / 测段观测高差 / 高差改正值(mm) / 改正后高差 / 高程 H / 备注；检核行给 **f_h =** 与 **f_h允 =**（按 系数×√L 自动算出，后面标注如「40√L，L = 0.2175 km」），超出允许值标红。列宽按内容固定分配，不会有一列吃掉整片空白

### 6. 角度测量

- 记录表按手簿排布：**测站 / 测回数 / 竖盘位置 / 目标 / 水平度盘读数（° ′ ″ 三格）/ 半测回角值 / 角度之差 / 一测回角值 / 角度之差 / 各测回平均角值**
- 每个测回占四行：左 A、左 B、右 A、右 B；测站、测回数、竖盘位置、半测回角值按行合并
- **左盘 / 右盘各自独立**：角度之差、一测回角值、角度之差在左右盘各占一格，不跨竖盘位置合并；数值统一写在右盘块，左盘三格留白
- **同一测站的多个测回共用「测站」格**（按站号 `stNo` 分组），整站纵向合并；点「增加测站」另起一站，「增加测回」继承当前站
- 每行右侧「编辑」可把**整站上移 / 下移**（站号与测回数自动重排），或删除这一测回（二次确认）；列名为「管理」
- **「各测回平均角值」每站各一格**，多个测站不会合成一格
- 默认新建 **1 站 / 1 个测回**；表下不再放读数说明文字，交互提示改由「编辑」弹窗给出
- 自动计算：半测回角值、半测回较差、一测回角值、与测站平均之差、各测回平均角值，并给出限差判定（半测回 ±40″、测回间 ±24″）

### 7. 数据分析

分**两步**：先在列表页选工作，再进入该工作自己的分析页。

- **列表页**（`#/export`）按工作类型筛选（全部 / 全站仪 / 水准 / 角度，带数量角标），下面按类型分组列出工作条目；**没点开任何工作时，页面上不显示任何数据**
- 点开某一条 → 进入 `#/analysis/<id>`：这一页只放这份工作的指标、图、表与导出，**没有工作切换入口**；左上角返回列表再换别的工作
- 该页提供四种处理/导出方式（见下）
- 概览指标：全站仪为点位数 / 连线数 / ΔN / ΔE；水准为测段数 / Σh / 总距离 / 闭合差；角度为测回数 / 平均角值 / 半测回与测回间最大较差
- 图：全站仪 → 点位平面坐标图；水准 → 里程—高程坐标图；角度 → 模拟角度图（∠AOB 即实测角值）
- **导出为图片**：把图连同标题与图注渲染成 PNG（3 倍像素密度），文件名带工作名
- **导出为 CSV**：按表分块导出，水准的记录表（Σ / 检核行）与成果表（Σ / f_h 行）、角度的记录表各成一块；合并单元格把内容写在首列、其余列留空，保证与表头对齐、粘进 Excel 不错列
- **智能纸图**（仅水准 / 全站仪）：输入纸张尺寸（cm），程序按图幅选一个整比（如 1:200）并生成坐标轴大图——图框四边即坐标轴，**坐标轴刻度直接标纸面 cm**（图框左边为 0，向右 / 向上数），点的位置就是纸上坐标；每点都有平行于坐标轴的浅灰虚线贯穿、标注带白描边不压线；**点色与点的类型颜色一致**；点数超过 60 时只画点、辅助虚线按间隔抽取，点号改看下方表格；下方给出「纸上量取」表（每点距左轴 / 距下轴多少 cm）与各线段的纸上长度，可直接照着在纸上定点
- 表：随类型自动列出对应数据列，另提供「复制表格」（制表符分隔，直接粘贴到 Excel / WPS）

### 8. 程序设置

「全站仪测绘 · 点的分类」：新建 / 修改 / 删除点位类型，可改名称、显示颜色、关键词（空格或逗号分隔）。默认提供碎部点、控制点（关键词「控制 / 原」）、测站点、辅助点（关键词「辅助 / 搬站」）四类。从「关于程序」页进入。

## 四、性能说明（v2.0.0）

v1.3.0 在 100 个点以上会明显卡顿，原因在网页逻辑而不是 APK：

| 旧实现的问题 | 120 点 | 200 点 |
|---|---|---|
| 连线列每行一个 `<select>`，每个含全部点号 → N² 个 `<option>` | 14 400 个 | 40 000 个 |
| 每次按键都重建全部下拉选项 | 每次按键重建 N² 节点 | 同 |
| 增行时整表重建 + 点号避让 O(N²)×8 | 285 ms | 648 ms |
| 整页 DOM 元素总数 | 17 843 | 45 603 |

v2.0.0 的做法：连线改为图上点选（不再有下拉）、增行只追加一行、标注避让改用网格哈希（O(N)）、SVG 改为节点池复用。

实测（Chromium 内核，200 个点）：打开 8.7 ms、一次按键 0.2 ms、单帧重绘 4.1 ms、增加一行 5.5 ms、元素总数 5 240。

同环境前后对比（jsdom，120 个点，排除设备差异）：

| 指标 | v1.3.0 | v2.0.0 |
|---|---|---|
| 打开工作 | 418 ms | 126 ms |
| 一次按键到重绘 | 40.5 ms | 1.6 ms |
| 增加一行 | 464 ms | 42 ms |
| DOM 元素总数 | 17 843 | 3 344 |
| `<option>` 节点 | 14 400 | 4 |

## 五、数据存储与备份

- 数据保存在浏览器 / WebView 的 **localStorage**，不上传任何服务器，不依赖网络
- 改动后约 0.7 秒自动保存；返回、切后台、关闭前都会补存
- 顶栏「保存」按钮可随时手动存一次（`Ctrl / ⌘ + S` 同效），存完提示具体时间
- **卸载软件、清理数据、更换设备都会丢数据**。重要数据请用工作页右上角「导出」备份为 `.cece.json`，或在工作管理里批量导出整包
- 数据格式已升级到 v2，旧版（v1.x）的存档/工作打开时会自动迁移，连线不会丢
