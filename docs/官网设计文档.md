## 0. 设计目标与定位

**官网是什么**：软件的门面与分发入口，一个独立的纯静态站，与主程序源码仓库分离。

**三个核心目标**（按优先级）：

1. **让访客快速理解价值** —— 10 秒内看懂"测策能帮我做什么"。
2. **顺利获取软件** —— 安卓走 APK 下载，iOS 走 PWA「添加到主屏幕」。
3. **学会使用** —— 教程页覆盖全部功能用法与计算逻辑。

**目标受众**：土木工程测量课程的师生（以学生为主），移动端（手机/平板）访问为主。

**一句话定位**：把全站仪、水准仪读出来的数据，变成看得懂的图和算好的成果。

**不包含**：鸿蒙版本（该端已停止维护，全站**不提供**鸿蒙下载入口或打包说明）。唯一例外是数据迁移说明中的「安卓、iOS、鸿蒙（卓易通）间可通过导出 / 导入互相迁移」一句，属用户明确要求保留的兼容性表述。

## 2. 全局设计规范

### 2.1 视觉：继承主程序 Design Token

官网复用主程序的配色变量，保证品牌一致：

| Token | 值 | 官网用途 |
|---|---|---|
| `--brand` | `#0f5f6b` | 主色：导航、主按钮、标题强调 |
| `--brand-strong` | `#0a4750` | 深色：hover、页脚背景 |
| `--brand-soft` | `#e4f1f3` | 浅青：区块底色、代码块底 |
| `--accent` | `#e0803a` | 强调橙：下载按钮、关键高亮、角标 |
| `--bg` | `#eef2f3` | 页面背景 |
| `--surface` | `#ffffff` | 卡片底 |
| `--text` | `#17272a` | 正文 |
| `--muted` | `#64777c` | 次要文字 |
| 圆角 | `14px` / `10px` | 卡片与按钮 |
| 阴影 | 柔和低对比 | 卡片浮起 |

品牌标识：直接复用 `icon.svg`（全站仪 + 水准尺 + 角度的测旗图形）。

### 2.2 技术方案

- **纯静态**：HTML + CSS + 原生 JS，零依赖、零构建，与主程序一致。
- **部署**：GitHub Pages（独立官网仓库，仓库名英文）。
- **响应式**：移动优先（受众用手机/平板访问），断点 `≥768px` 与 `≥1024px`。
- **无障碍**：语义化标签、对比度达标、按钮可触达。
- **SEO / 分享**：`title` / `description` / Open Graph 标签；`apple-touch-icon`（180×180）与 `favicon` 就位。
- **性能**：无框架，首屏静态资源极轻。

## 5. 教程页设计（重点）

**目标**：覆盖全部功能用法 + 计算逻辑，让零基础学生能照做。

### 5.0 页面骨架

顶部：教程目录（锚点跳转，粘性侧栏或顶部 chip）。
内容分五章：通用操作 → 全站仪测绘 → 水准测量 → 角度测量 → 数据分析。

### 5.1 通用操作

- **新建工作**：选类型（全站仪 / 水准 / 角度）→ 填名称（默认按日期时间）→ 水准额外填起点高程与容许闭合差系数 → 创建并开始。
- **工作管理**：搜索、按类型筛选、四种排序、批量导出/删除、从文件导入（单个或整包备份）。
- **自动保存**：停止输入约 0.5 秒自动落盘；顶栏「保存」按钮或 `Ctrl/⌘ + S` 手动保存；数据存本机浏览器 localStorage。
- **导出 / 导入**：导出为 `.cece.json`；换设备导入恢复。

### 5.2 全站仪测绘

**表格**：列 = 排序 | 点号 | 棱镜高 | N(X) | E(Y) | H(Z) | 备注。数字格统一三位小数。

**要点**：
- 直接录入点位坐标，**N(X) 增大点向上、E(Y) 增大点向右**（图上即时成图）。
- **点号智能编号**：空格聚焦时按"上一个数字点号 +1"给出浅灰预测，离焦即落值。
- **点位分类**：备注命中关键词自动归类（默认四类：碎部点 / 控制点 / 测站点 / 辅助点）；图上「编辑点」可手动改类型；分类与关键词在「程序设置」自定义。
- **连线**：图上点选多个点连折线，可改颜色 / 删除。
- **拖拽排序**：按住首列滑块上下拖动调整顺序。

> 说明：本模块是「坐标录入 + 成图」，水平角/距离到坐标的换算由全站仪或前序手工完成，程序不在此处做极坐标解算。

### 5.3 水准测量（含计算逻辑）

**记录表**（每测站两行：后视点行 / 前视点行）：
- 读数 a（后视）、b（前视）与视距分别填入。

**计算逻辑（程序自动完成）**：

| 项 | 公式 | 说明 |
|---|---|---|
| 测段高差 | `h = a − b` | 后视减前视 |
| 各点高程 | `H = H起 + Σh` | 逐段累计 |
| 检核式 | `Σa − Σb = Σh = H终 − H始` | 三项应相等 |
| 闭合差 | `f_h = Σh实测 − (H终 − H始)已知` | 单位 m |
| 改正数 | `v_i = −f_h × (L_i / ΣL)` | 按距离比例反号分配；缺距离时按测段数均分；单位 mm |
| 改正后高差 | `h' = h + v / 1000` | 再由改正后高差累计得改正后高程 |
| 容许闭合差 | `f_h允 = c√L` | c 默认 40，L 为路线长（km）；超限标红 |

**闭合 / 附合自动识别**：标题栏「H终」留空或等于起点高程 → 闭合；填不同值 → 附合。

**成果表**：测段编号 / 点号 / 测段距离 / 观测高差 / 高差改正值(mm) / 改正后高差 / 高程。

### 5.4 角度测量（含计算逻辑）

**测回法**：每测回录入 4 个读数 —— A 盘左、B 盘左、A 盘右、B 盘右。

**计算逻辑（程序自动完成）**：

| 项 | 公式 | 说明 |
|---|---|---|
| 半测回角值 | `β左 = B盘左 − A盘左`；`β右 = B盘右 − A盘右` | 归化到 [0°,360°) |
| 一测回角值 | `β = (β左 + β右) / 2` | 圆周平均，避免 359°/1° 跨界 |
| 半测回较差 | `β左 − β右` | 限差 **40″** |
| 各测回平均角值 | 各有效一测回角值的圆周平均 | 按测站分组 |
| 测回间较差 | 各测回角值与站平均之差 | 限差 **24″** |

**度分秒输入**：支持 `45°30′30″`、`45 30 30`、`45:30:30` 等格式，程序统一解析。

### 5.5 数据分析

- 选工作 → 概览指标 → 图表 → 数据表。
- 三类图表：全站仪「平面坐标图」、水准「里程—高程图」、角度「角值柱状图」。
- 导出三种：导出图片（PNG）、导出 CSV（Excel 可用）、智能纸图（按纸张尺寸选比例尺，附「纸上量取」表，仅全站仪/水准）。
